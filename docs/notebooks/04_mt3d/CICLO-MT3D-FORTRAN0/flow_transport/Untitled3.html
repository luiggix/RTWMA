    MODELO DE FLUJO Y TRANSPORTE USANDO MF6 Y MT3D-USGS PARA LAS ESPECIES SULFATO Y CALCIO

    1️⃣ Importación de librerías

    Se importan las bibliotecas necesarias como flopy, numpy, matplotlib, os y utilerías de archivos binarios, que permiten construir, ejecutar y visualizar modelos de flujo y transporte subterráneo.

    2️⃣ Definición de rutas y ejecutables

    Se configuran las rutas y ubicación de los ejecutables MODFLOW 6 (mf6) y MT3D-USGS (mt3d-usgs_1.1.0_64.exe).

    3️⃣ Configuración de la simulación

    Se define una simulación de flujo 1D usando MODFLOW 6 con: LX=30 m, LY=1 m, LZ=1 m, para un periodo de 40 días dividido en 40 pasos de tiempo.

    4️⃣ Malla y propiedades hidráulicas

    Se define la malla espacial y las propiedades hidráulicas del acuífero de 1 capa, 1 renglón y 30 columnas con una conductividad hidráulica = 1.0m/día y porosidad = 0.5.

    5️⃣ Condiciones de frontera

    Se especifican condiciones de frontera tipo Neumann de Flujo prescrito en la frontera izquierda CFI = 0.2 m³/d, inyectando un fluido con concentración específica para cada especie. En la frontera derecha se prescribe una carga hidráulica CFD = 1 m.

    Modelo de Flujo MODFLOW 6

    6️⃣ Ejecución del modelo de flujo

    Se escriben los archivos de entrada del modelo y se ejecuta MODFLOW 6. Esto permite resolver la ecuación de flujo y calcular la distribución de cargas hidráulicas.

    7️⃣ Visualización de resultados hidráulicos

    Se visualizan los resultados de carga hidráulica y descarga específica obtenidos de los archivos .hds y .bud.

    Modelo de Transporte MT3D-USGS

    8️⃣ Configuración del modelo de transporte

    Se crea el modelo de transporte asociado al flujo, incluyendo las especies sulfato y calcio. Esto permite simular cómo las concentraciones evolucionan en el tiempo dentro del flujo de agua subterránea.

    9️⃣ Condiciones iniciales y de frontera

    Se establecen condiciones iniciales y de frontera para cada especie: c₁ para el sulfato y c₂ para el calcio, y condiciones iniciales y de frontera de concentración prescrita c₁ = 1.0000329 y c₂ = 3.294 × 10⁻⁵, con pulsos en la celda 11 con c₁₁₂ᵢ = 200 para el sulfato y c₂₁₂ᵢ = 1.647 × 10⁻⁷ para el calcio.

    🔟 Advección, dispersión y parámetros

    Se definen los esquemas de advección y dispersión, junto con parámetros como dispersividad y difusión molecular. Esto determina cómo se mueve y se mezcla el contaminante con el agua en el acuífero.

    Reacciones Químicas

    1️⃣1️⃣ Ejecución y resultados sin reacciones

    Se ejecuta MT3D-USGS sin el paquete de reacciones (RCT) para obtener un caso base de transporte puro, sin transformación química. Sirve como referencia para evaluar el impacto de las reacciones.

    1️⃣2️⃣ Inclusión del paquete RCT

    Se activa el paquete RCT para incluir adsorción lineal y decaimiento de primer orden. Esto permite simular la interacción química entre el contaminante y el medio poroso.

    1️⃣3️⃣ Configuración de adsorción y decaimiento

    Se asignan parámetros como la densidad aparente del suelo (rhob) y coeficientes de reacción (rc1, rc2) para modelar los procesos químicos de cada especie. Esto afecta la velocidad de retención o transformación del contaminante.

    1️⃣4️⃣ Ejecución del modelo con reacciones

    Se ejecuta el modelo con reacciones habilitadas y se generan archivos .m3d con los resultados. Esto permite comparar los efectos de las reacciones frente al transporte puro.

    Visualización de Resultados

    1️⃣5️⃣ Gráficas sin reacciones

    Se grafican las concentraciones de las especies para el caso sin reacciones. Esto permite entender el comportamiento del transporte sin procesos químicos involucrados.

    1️⃣6️⃣ Gráficas con reacciones

    Se visualizan las concentraciones simuladas con el paquete RCT, comparando su evolución con el caso sin reacciones. Esto ayuda a cuantificar el efecto de la adsorción y el decaimiento.
