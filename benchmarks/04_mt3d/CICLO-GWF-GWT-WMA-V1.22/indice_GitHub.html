5. Git como un sistema de archivos

1. Git gestiona los archivos de un repositorio como un sistema de archivos
miniatura

6. Los tres estados de los archivos en Git.

1. Modificado (modified).
2. Preparado (staged).
3. Confirmado (committed).

7. Configuración inicial

1. Para que Git identifique el autor de cada cambio en los archivos de un
repositorio se debe configurar el nombre de usuario y el correo
electrónico usando los comandos que siguen:

git config --global user.name “nrbrtvr”
git config --global user.email “nrbrtvr@gmail.com”

8. Creación de un repositorio local

1. mkdir curso
Crear un directorio en donde estarán los archivos del repositorio.

2. cd curso
Cambiarse al directorio antes creado.

3. git init
Inicializar el repositorio. Esto se realiza una sola vez.

9. Listar los archivos actuales del directorio

ls -la

10. Checar el estado actual del repositorio con el comando

git status

11. revisar la bitácora de cambios de los archivo usando el comando

git log

12. Crear y modificar los archivos del repositorio.

1. git add lista de archivos
Preparar los archivos modificados
2. git commit -m “ Comentario ...”
Confirmar los cambios

13. Sincronizar un repositorio local con el remoto en GitHub.

1. cd dir_repo
Cambiarse al directorio del repositorio.
2. git remote add origin remote
Agregar la dirección del repositorio remoto.
En este caso remote puede ser en formato HTTPS o en formato SSH.
Solo se hace una vez.
3. git push -u origin main
Subir los archivos locales al repositorio remoto.

14. Clonar un repositorio de GitHub

1. git clone dir_repo_github
Clonar el repositorio de la dirección dir_repo_github. Puede ser usando el
protocolo HTTPS o el SSH. La dirección del repositorio se obtiene del sitio en GitHub.
2. cd dir_repo
Cambiarse al directorio del repositorio recién clonado y comenzar a trabajar en él.

15. Crear o modificar los archivos que componen el repositorio.

1. cd dir_repo
Cambiarse al directorio del repositorio.
2. git pull
Obtener la última versión del repositorio. Al iniciar el día, este debe ser el primer comando que se realice.

16. Crear y modificar los archivos del repositorio

1. git add lista_de_archivos
Agregar la lista_de_archivos modificados al área de espera.
2. git commit -m “mensaje”
Confirmar los cambios que están en el área de espera.
3. git push -u origin main
Enviar los cambios al repositorio remoto en GitHub. Al finalizar el día de trabajo, este debe
ser el último comando que se realice.
