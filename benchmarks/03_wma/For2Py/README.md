# CFFI

[C Foreign Function Interface for Python](https://cffi.readthedocs.io/en/stable/) 
Interactúa con cualquier (casi) código de C desde Python basado en declaraciones tipo **C** que son similares los encabezados de los archivos de encabezado (.h) o de la documentación.
